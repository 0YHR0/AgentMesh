# AgentMesh v0.2.0-alpha.4

Release date: 2026-09-29 · Pre-release

This release adds an explicitly enabled Feishu notification adapter. When a Task becomes completed,
failed, or waiting for human review, AgentMesh records a delivery job atomically with the Task
transition. An independent notifier sends a card to a configured Feishu group and retries failures;
the Task itself is never failed by a notification outage. Feishu's message UUID uses the stable job
ID to reduce duplicate cards.

Every profile, including `full`, leaves `feishu_notifications` off. The operator must supply a
Feishu custom app, bot permissions, App ID/Secret, and group `chat_id`, then start the Compose
`feishu` profile. Cards omit the Task objective/result by default; excerpts and an HTTPS Console
link are optional. See the [English setup guide](../integrations/feishu-notifications.md) or
[Chinese setup guide](../integrations/feishu-notifications.zh-CN.md).

This is outbound notification only. Group-chat commands and approvals remain future work, and live
Feishu delivery requires a separately configured test app/group. The release includes PostgreSQL
migration `20260929_0055`; apply it before starting API/Worker on the new version. The product
remains an evaluation/non-critical single-team Alpha.

Source changes: [compare with Alpha.3](https://github.com/0YHR0/AgentMesh/compare/v0.2.0-alpha.3...v0.2.0-alpha.4).
