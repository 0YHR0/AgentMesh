# AgentMesh v0.2.0-alpha.1

Release date: 2026-09-29 · Pre-release

This Alpha makes the single-team control plane easier to try and inspect. It adds a focused
English/Chinese Console, guided employee and task setup, secure model connections and reviewed
memory, while keeping advanced governance and framework-neutral runtime cutover opt-in.

## Start here

```bash
git clone https://github.com/0YHR0/AgentMesh.git
cd AgentMesh
docker compose up --build
```

Open <http://localhost:8000>. The default deterministic executor needs no model key. Follow the
[five-minute guide](../getting-started.md) or the
[real-DeepSeek customer-feedback walkthrough](../scenarios/customer-feedback-deepseek.md). For a
real provider key, first enable authentication and use HTTPS or the
[SSH-only administration path](../operations/model-connections-ssh.md). Never enter credentials on
an anonymous public HTTP deployment.

## Highlights since v0.1.0-alpha.1

- The Console now guides Direct, Reviewed, and Coordinated task creation, employee assignment,
  dependencies, plan review, status, and durable Mission Map replay. Its default is English with a
  Chinese switch. The former game-style Office UI is retired; `/world` and `/world-3d` redirect to
  the Console without removing Company, employee, or historical Task records.
- Administrators can configure encrypted OpenAI/DeepSeek model connections and publish distinct
  employee versions. Built-in reviewed PostgreSQL memory needs no external memory service.
- A private acceptance run completed a Direct task and a three-employee Coordinated task with
  DeepSeek. Screenshots and the reproducible user journey are in the walkthrough. The public demo
  remains deterministic and has no provider credential.
- Framework-neutral Runtime contracts and LangGraph/subprocess conformance are available for
  qualification. Managed coordinated cutover remains **disabled by default**; the
  [A4.2d report](../qualification/a4-2-parity.json) records safety differences rather than
  claiming production parity.
- Company goals, Operations, Business Objects, memory, finance, Packs, and trusted Runtime
  Extensions provide optional building blocks. Music Studio remains a keyless deterministic demo;
  live generation providers are not included.

## Upgrade and support boundary

Back up PostgreSQL and Artifacts before upgrading an existing Alpha deployment; use the
[restore runbook](../operations/slo-and-restore.md) and verify migration/readiness in a test
environment before replacing a live instance. Keep existing feature-gate choices explicit.

This is for evaluation and non-critical **single-team** deployments. It is not qualified for
multi-tenant isolation, managed HA/PITR, production capacity, or default non-LangGraph runtime
cutover. See [implementation status](../implementation-status.md), the
[v1 boundary](../v1-completion-scope.md), and [production hardening #160](https://github.com/0YHR0/AgentMesh/issues/160).
