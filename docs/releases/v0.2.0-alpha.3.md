# AgentMesh v0.2.0-alpha.3

Release date: 2026-09-29 · Pre-release

This Alpha improves the Task result experience. The Console shows the readable output text first,
with the producing employee and any linked Artifact Versions nearby. Raw JSON remains available
under **View raw JSON** for auditing and debugging.

For Coordinated Tasks whose system supervisor is deterministic, the result view selects completed
terminal work items rather than mistaking the supervisor's generic completion message for the
deliverable. Demo-only outputs carry an explicit warning; candidate outputs awaiting review are
not labeled as final. Existing Task data remains unchanged, and no migration is needed.

This is a presentation improvement, not a model upgrade: the public demo's deterministic employee
still does not generate substantive answers. The Console currently previews text and links
supported text/JSON Artifacts; it does not yet provide a chat-like agent message ledger or external
group-chat integration. For a real-model example, see the
[customer-feedback walkthrough](../scenarios/customer-feedback-deepseek.md).

All other features and limitations remain as documented in
[v0.2.0-alpha.1](v0.2.0-alpha.1.md) and the
[Alpha.2 hotfix](v0.2.0-alpha.2.md). This remains an evaluation/non-critical single-team release.

Source changes: [compare with Alpha.2](https://github.com/0YHR0/AgentMesh/compare/v0.2.0-alpha.2...v0.2.0-alpha.3).
