# AgentMesh v0.1.0-alpha.1

Release date: 2026-07-27

This is the first public Alpha release of AgentMesh and the first release-qualified implementation
of the supported single-team v1 scope.

## What this release proves

AgentMesh can durably coordinate direct, independently reviewed, and multi-Agent DAG work while
keeping PostgreSQL authoritative and making every Run, Attempt, Handoff, Plan Patch, governed
Tool call, A2A delegation, Artifact, approval, usage record, and operator intervention observable.
The Mission Map turns that durable evidence into a live, replayable operator view.

## Quick start

```bash
docker compose up --build
```

Open `http://localhost:8000`. To create the deterministic governed showcase:

```bash
AGENTMESH_FEATURE_PROFILE=full docker compose up -d
docker compose --profile showcase run --rm showcase
```

PowerShell:

```powershell
$env:AGENTMESH_FEATURE_PROFILE = "full"
docker compose up -d
docker compose --profile showcase run --rm showcase
```

No paid API or model credential is required for the deterministic baseline.

## Qualification evidence

- 326 non-PostgreSQL tests passed with 82.49% line coverage.
- 19 isolated PostgreSQL/Redis integration tests passed.
- Alembic check, downgrade, and re-upgrade passed through revision `20260723_0033`.
- Direct, reviewed, and coordinated Compose E2E paths passed.
- An isolated database was deliberately emptied and restored from a verifiable backup.
- The restore recovered Task/Run/Attempt lineage, a governed action, a shared replay bookmark, and
  a 70,023-byte content-addressed Artifact with matching SHA-256.
- The full Compose E2E suite passed again after restore.

## Alpha boundary

This release is ready for evaluation and non-critical single-team use. It is not a claim of
multi-tenant isolation, managed high availability, disaster-recovery certification on a chosen
cloud, or production capacity certification. Those boundaries are explicit in
[v1 completion scope](../v1-completion-scope.md).
